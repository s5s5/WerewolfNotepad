下面按四个板子分别说明。先说一句关键的：**网易《狼人杀-官方正版》很多角色有过改名/皮肤名，面杀圈和网杀圈的叫法也不一样**，所以我把官方名、常用俗称、面杀对应名都列出来了。

---

## 一、12人标准场（预女猎白 / 预女猎愚）

**配置**：狼人×4 ｜ 预言家、女巫、猎人、白痴（愚者）｜ 平民×4
**规则**：暗牌屠边局，有警长，双爆吞警徽；12人场女巫**全程不可自救**

| 角色   | 技能                                                                                                   | 别名 / 备注                                          |
| ------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| 狼人   | 每晚共同袭击一名玩家，白天可自爆                                                                       | 普狼、小狼                                           |
| 预言家 | 每晚查验一名玩家是好人还是狼人                                                                         | 预、预言家（安娜/维尔）                              |
| 女巫   | 一瓶解药 + 一瓶毒药，每晚最多用一瓶；解药可救当晚被狼刀的人，毒药可毒杀一人                            | 女巫（梅琳娜）；**12人场不能自救**                   |
| 猎人   | 被狼刀或被投票放逐时可翻牌开枪带走一名玩家                                                             | 猎、猎人（帕特里克）；**被女巫毒死不能开枪**         |
| 白痴   | 被**投票放逐**时翻牌，免疫本次放逐；此后可正常发言，但不能投票也不能被投票，狼人需再追刀一次才真正出局 | **官方现已改名为「愚者」**（角色名莫林），俗称"白神" |
| 平民   | 无技能                                                                                                 | 村民、民、闭眼玩家                                   |

**板子别名**：预女猎白、预女猎愚、标准场、12人标准。老玩家说"白痴"和"愚者"是同一张牌。

## 二、12人奇迹商人

**配置**：狼王×1、狼人×3 ｜ 预言家、女巫、守卫、奇迹商人 ｜ 平民×4
**规则**：暗牌屠边局，有警长，双爆吞警徽，女巫全程不能自救

| 角色                 | 技能                                                                                                                                                               | 别名 / 备注                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| **奇迹商人**         | 每晚**第一个行动**，选一名其他玩家成为"幸运儿"，把**查验 / 毒药 / 守护**三选一交给TA，每局限一次。若幸运儿是狼人，狼人不会获得技能，且**商人次日出局**（交易失败） | 简称**奇商**；本名碧翠丝·卡文迪许，萌娘百科别号"老板" |
| 狼王                 | 拥有普通狼人的刀人能力；被**放逐、被猎人带走、夜间自刀**出局时可开枪带走一名玩家；**白天自爆或被女巫毒死不能开枪**                                                 | 狼枪；注意别和"白狼王"混淆——白狼王是白天自爆带人      |
| 守卫                 | 每晚守护一名玩家，使其当晚不被狼刀；**不能连续两晚守护同一人**                                                                                                     | 盾                                                    |
| 预言家 / 女巫 / 平民 | 同上                                                                                                                                                               | —                                                     |

**补充要点**：

- 幸运儿拿到技能**不必当场用掉**，只要还活着，可以在拿到技能当夜及之后任意一个夜晚使用，也可以不用。
- 赋予的技能与角色原有技能互不干扰：给预言家查验，预言家当夜可验两人（但不能重复验同一人）；给女巫毒药，女巫可在幸运儿行动阶段**额外**用一瓶毒。
- 这个板子**没有猎人**，神职是"预女守商"。

## 三、12人觉醒骑士

**配置**：狼人×3、觉醒狼美人×1 ｜ 预言家、女巫、觉醒守卫、觉醒骑士 ｜ 平民×4（2026年8月13日上线）

| 角色                 | 技能                                                                                                                                                                                                                                         | 别名 / 备注                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **觉醒骑士**         | 白天**放逐发言阶段**可随时翻牌，选择一名玩家**决斗**：对方是狼人→对方出局，骑士可选择是否继续决斗；对方是好人→骑士与被决斗者**同时出局**，继续白天原本发言流程。**每名玩家只能被决斗一次**                                                   | 圣剑骑士、骑士（觉醒版）；老版"骑士"也是决斗机制，但老版只能决斗一次且不能连续 |
| **觉醒守卫**         | 每天可选择在**夜晚阶段或白天放逐发言阶段**使用一次觉醒守护，被守护者**不会以任何方式出局**；每天只守护一人，**不能连续两天守护同一人**。夜里守护的人，白天也不会被放逐（持续到当天白天结束）；被守护者白天被放逐会显示平安日、无遗言直接入夜 | 觉醒盾；本名休伯特·威廉                                                        |
| **觉醒狼美人**       | 不能自爆、不能自刀；狼队行动后**单独睁眼**发动"挽歌幻象"魅惑一名玩家；**第一次面临出局时，被魅惑玩家【替代】其出局**（无法被守卫守住）；技能**每隔一晚才能发动一次**，全局只生效一次；第二次受害直接出局                                     | 觉醒狼美；本名塔莉莎·莱斯利                                                    |
| 预言家 / 女巫 / 平民 | 同上                                                                                                                                                                                                                                         | —                                                                              |

**三张觉醒牌的关键互动**：

- 骑士决斗了已发动魅惑的觉醒狼美人 → 魅惑目标替代出局，骑士**可以继续决斗**别人（但不能再决斗同一个狼美人）。
- 觉醒守卫可以守护因骑士决斗而出局的人，**包括决斗失败（决斗到好人）的骑士本人**。
- 骑士第一天决斗狼人后若选择不再继续，**第二天不能再发动**决斗。

## 四、12人镜隐迷踪

**配置**：狼人×3、觉醒隐狼×1 ｜ 魔镜少女、女巫、猎人、守卫 ｜ 平民×4（2023年10月28日六周年上线）

| 角色                      | 技能                                                                                                                                                                                              | 别名 / 备注                          |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| **魔镜少女**              | 每晚查验一名玩家的**具体身份**（直接报出角色牌，而不是只报好人/狼人），**不可重复查验同一人**                                                                                                     | 面杀圈叫**「通灵师」**；本名薇薇安   |
| **觉醒隐狼**              | 不与狼队见面（互相不知道身份）、不能自爆、不参与常规狼刀；**3名狼人全部出局后才能带刀**。可在任意一夜选择一名玩家**模仿**：**立刻获得目标身份**（被查验时显示该身份），**当夜结束后获得目标技能** | 面杀圈叫**「机械狼」**；本名安托鲁斯 |
| ├ 模仿狼人                | 成为带刀狼后获得**额外的一次性狼刀**                                                                                                                                                              | —                                    |
| ├ 模仿魔镜少女            | 之后每晚可查验一名玩家的具体身份                                                                                                                                                                  | —                                    |
| ├ 模仿女巫                | 获得**一瓶毒药**（无解药）                                                                                                                                                                        | —                                    |
| ├ 模仿守卫                | 每晚守护一人，本板为加强版，**既挡狼刀也挡毒药**，仍不能连守同一人                                                                                                                                | —                                    |
| ├ 模仿猎人                | 出局后可开枪带走一人                                                                                                                                                                              | —                                    |
| └ 模仿平民                | 无任何技能，只获得平民身份                                                                                                                                                                        | —                                    |
| 女巫 / 猎人 / 守卫 / 平民 | 同标准场规则；本板女巫**全程不可自救**                                                                                                                                                            | —                                    |

**板子别名**：面杀和主播圈普遍叫**「机械狼通灵师」**，本质就是同一个板子换皮。
