# 狼人杀记录器

一款简洁高效的狼人杀游戏记录工具，帮助你在游戏中快速记录每位玩家的发言要点。

面向 12 人标准愚者板配置：四民 · 四狼 · 预女猎愚 · 警徽流。

## 主要功能

- **席位状态盘**：一览全场 12 个席位的当前状态（倒牌、上警竞选、愚者翻牌免死等标记）
- **玩家标记**：为每位玩家打上底牌标注、信誉定性、行为死因等标签，随时点击移除
- **发言拼词记录**：通过预设词块快速拼出发言要点，也支持自由文字补充，按玩家、按轮次归档
- **局势流水**：所有发言、夜间死亡、警长竞选、投票记录按时间顺序呈现，支持编辑、删除、插入分割线，可按当前玩家筛选
- **夜晚死亡记录**：快速登记平安夜或倒牌玩家，自动生成结算记录
- **警长竞选与投票**：分场景（警选投票 / 白天放逐 / 平票 PK）记录候选人与得票情况
- **快捷报验人**：为预言家角色提供验人时间、目标、结果的快速录入
- **本地保存**：所有记录自动保存在浏览器本地，刷新页面不丢失
